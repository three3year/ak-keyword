# 01 — 外觀開關

**What to build:** 標題列在伺服器切換右邊多一個外觀開關,三格「系統 / 亮 / 暗」,一直顯示(資料載入中與錯誤頁也有)。預設跟隨系統,行為和現在一樣,系統切換亮暗時頁面即時跟著換。選「亮」或「暗」後不論系統設定都固定用該色;選擇會被記住,下次開站沿用,存不了就回到跟隨系統。重新整理時不會先閃一下另一色。完成後桌面與手機都能切外觀;手機標題列的排法留給 02。規格見 [spec.md](../spec.md)。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 外觀開關樣式與單選語意同伺服器切換;群組名稱「外觀」,鈕面「系統」「亮」「暗」,懸停文字與無障礙名稱為「跟隨系統」「亮色」「暗色」;可用鍵盤操作。
- [x] 開關不等資料載入就出現;伺服器切換尚未出現時,外觀開關單獨出現在原位置。
- [x] 跟隨系統時頁面配色完全由系統偏好決定,系統切換時不必重新整理就跟著換。
- [x] 選亮色或暗色時,所有區塊(結果卡、關鍵字面板、提示框、幹員詳情、頁尾)與瀏覽器自畫的捲軸、輸入框都用該色,不受系統偏好影響。
- [x] 亮色與暗色配色令牌的值不變,只改生效條件。
- [x] 選擇存在和伺服器切換同一個瀏覽器儲存模組;讀到不認得的值或存取失敗時當跟隨系統。
- [x] 網頁最前面先讀記住的外觀並在畫面出現前套用,讀取規則與儲存模組一致;固定外觀而系統是另一色時,重新整理不閃色。
- [x] 桌面 e2e(真實資料,底色只比相對關係、不寫死色碼):系統模擬亮色時預設選「系統」;切「暗」底色改變,重新整理後仍為暗色且選「暗」;切回「系統」底色回到亮色。系統模擬暗色時選「亮」為亮色,系統亮暗來回切換時維持亮色。選「系統」時切換系統亮暗,頁面即時跟著換。三格有全名的無障礙名稱,群組名稱為「外觀」。
- [x] 既有 e2e 全部通過。
