# 02 — 手機標題列兩行與關鍵字懸浮鈕

**What to build:** 手機寬度下,標題列固定兩行:第一行標題,第二行伺服器切換與外觀並排。原本在標題列的「關鍵字」鈕改成固定在畫面右下角的膠囊懸浮鈕,強調色底、白字,文字照舊顯示已選搜尋條件的數量,例如「關鍵字(2)」;抽屜打開時隱藏,關了再出現。內容底部多留懸浮鈕的高度,捲到底時最後一張結果卡不被擋住。桌面版面不變。規格見 [spec.md](../spec.md)。

**Blocked by:** 01 — 外觀開關

**Status:** ready-for-agent

- [x] 手機寬度下標題列固定兩行,不論手機寬度,伺服器切換與外觀都在標題下方的同一行。
- [x] 「關鍵字」鈕不在標題列,改為右下角膠囊懸浮鈕;捲動時位置不變;數量規則照舊(只算搜尋條件,不算職業條件)。
- [x] 抽屜打開時懸浮鈕隱藏,關閉後重新出現。
- [x] 手機寬度下內容底部多留懸浮鈕的高度,捲到底時最後一張結果卡完整露出。
- [x] 桌面不顯示懸浮鈕,桌面標題列除了 01 加的開關外不變。
- [x] 手機 e2e:伺服器切換與外觀在同一行且在標題下方;「關鍵字」鈕在畫面右下角,選了搜尋條件後顯示數量;打開抽屜時看不到它,關了又出現;沒有水平捲動。
- [x] 既有手機 e2e 用名稱找抽屜鈕的寫法照樣通過。
