# 05 — 召喚物與阿米婭形態

**What to build:** 召喚物的技能與天賦敘述算在所屬幹員名下，敘述來源標「召喚物」(例如「召喚物技能」)。只靠召喚物上寒冷的幹員點寒冷也會出現。阿米婭的每個職業形態各自成為一筆結果，職業依形態而定。

**Blocked by:** 03 — 天賦與特性(無模組)

**Status:** resolved

- [x] 阿米婭各職業形態(依阿米婭形態表)各成一位幹員，各自的技能、天賦、特性、職業正確
