# 06 — 效果類型

**What to build:** 每段命中敘述對每個關鍵字都有效果類型(施加、利用、抵抗、其他)，結果上會顯示。玩家可以複選效果類型篩選，預設只勾「施加」;多關鍵字時，篩選套用到每個已選關鍵字。維護者在建置後會拿到一份待複核清單，列出還沒複核的配對;覆寫檔裡的判定一律優先於規則。

**Blocked by:** 01 — 骨架與寒冷直通

**Status:** ready-for-agent

- [ ] 判定單位是「一段敘述 × 一個關鍵字」的配對
- [ ] 句型規則:例如「使…陷入 X」「造成…X」判為施加，「對 X 狀態的敵人」判為利用，「不會被 X」「免疫 X」判為抵抗，其餘判為其他
- [ ] 覆寫檔以敘述文字雜湊加關鍵字為鍵，記錄效果類型與是否已複核;建置時覆寫優先於規則;覆寫檔納入版控
- [ ] 建置輸出待複核清單:雜湊還不在覆寫檔裡的配對(含原文、關鍵字、規則判定結果)
- [ ] 介面有效果類型複選，預設只勾施加;每段命中敘述顯示其效果類型
- [ ] 多關鍵字 AND 時，每個已選關鍵字都要有一段效果類型符合勾選的命中敘述
- [ ] 「建置 → 查詢」測試涵蓋四種規則判定、覆寫優先、待複核清單只列新增或變動的配對
