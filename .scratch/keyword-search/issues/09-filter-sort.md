# 09 — 篩選與排序

**What to build:** 玩家可以依星級、職業與分支篩選結果。結果依星級高到低、職業(遊戲內職業順序)、實裝新到舊排序。結果上方顯示幹員數量;沒有結果時顯示「沒有符合的幹員」，並列出目前生效的條件。

**Blocked by:** 01 — 骨架與寒冷直通

**Status:** resolved

- [x] 星級複選篩選
- [x] 職業與分支篩選
- [x] 排序:星級高 → 低，再依職業(先鋒、近衛、重裝、狙擊、術師、醫療、輔助、特種)，最後實裝新 → 舊
- [x] 確認實裝順序的資料來源;遊戲資料沒有可靠欄位時，以幹員表順序近似，並在介面上註明
- [x] 結果數量顯示;沒有結果時的提示列出生效條件
- [x] 「建置 → 查詢」測試涵蓋星級、職業篩選與排序

## Comments

實裝順序的資料來源:遊戲資料沒有實裝時間欄位(幹員表的 sortIndex 是拼音順序、預設造型的 getTime 為 0)。
潛能信物(item_table 的 p_char_*)的 sortId 前綴對應星級、同星級內依實裝先後遞增,以此近似;
沒有潛能信物的少數幹員視為最舊。介面的排序說明標「近似」並以提示說明來源。
