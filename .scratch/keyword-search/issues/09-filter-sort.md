# 09 — 篩選與排序

**What to build:** 玩家可以依星級、職業與分支篩選結果。結果依星級高到低、職業(遊戲內職業順序)、實裝新到舊排序。結果上方顯示幹員數量;沒有結果時顯示「沒有符合的幹員」，並列出目前生效的條件。
