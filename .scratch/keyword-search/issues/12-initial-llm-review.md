## Comments

### 2026-10-19 首次全量複核結果

- 待複核 1579 個配對,分 8 批由 session 內的子代理逐筆判定,寫成判定檔後以 `build/applyReview.ts` 寫進 `data/effect-overrides.json`;重新建置後待複核為 0。
- 規則與複核不同的約 365 筆(約 23%)。另做一次一致性統一(28 筆):「自身不受鼓舞影響」→ 抵抗;Ave Mujica 陣營標籤 → 其他;蓄力/過載的「額外效果」→ 施加。
- 抽查:寒冷施加(凜御銀灰、聖聆初雪、靈知、極光…)、寒冷利用(靈知特性)、凍結抵抗(凜御銀灰、老鯉)、凍結利用(靈知、極光)皆正確。

### 規則常判錯的句型(供改進 build/effectType.ts)

| 句型 | 規則判定 | 正確 | 例 |
| --- | --- | --- | --- |
| 機率/攻擊附帶的暈眩,句中有「攻击力提高至」「对…」 | 利用 | 施加 | 有25%概率晕眩目标2秒 |
| 偷取 | 利用 | 施加 | 偷取目标40点防御力 |
| 範圍或區域使敵人「受到」效果(無「使」字) | 其他 | 施加 | 军旗周围8格敌人受到停顿和25%的脆弱效果 |
| 效果詞當動詞或主語在前:「敌人被停顿」「所有敌人失重」「诱导…敌人」 | 其他 | 施加 | 攻击范围内的所有敌人被停顿 |
| 自身進入狀態(起飛、閃避、持續攻擊、隱匿、移動) | 其他 | 施加 | 部署后立刻起飞、拥有30%的物理闪避 |
| 強化自己既有的效果 | 其他 | 施加 | 略微延长特性停顿的持续时间 |
| 回復、降低、吸收、清除元素損傷 | 其他 | 抵抗 | 友方单位受到的元素损伤降低28% |
| 抵消自身受到的控制 | 其他 | 抵抗 | 抵消自身受到的下一次晕眩/冻结 |
| 敵人觸發/爆發時、處於狀態的友方或自身獲得加成 | 其他 | 利用 | 敌人灼燃损伤爆发开始时…、拥有抵抗的友方单位… |
| 無視/解除敵人的閃避或隱匿 | 抵抗/施加 | 其他 | 无视闪避、使敌人隐匿失效 |
