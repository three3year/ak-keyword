# 02 — 多關鍵字與面板

**What to build:** 玩家可以同時選多個關鍵字，只列出全部都具備的幹員(AND)。關鍵字面板依維護者清單分組(控場、減益、增益、元素傷害等)，清單沒列到的新術語自動歸到「未分組」。面板上方可以打字過濾，也有一鍵清除。懸停或點開關鍵字按鈕與命中敘述中的高亮詞時，顯示該術語的官方定義(定義中巢狀的術語也正確呈現)。

**Blocked by:** 01 — 骨架與寒冷直通

**Status:** resolved

- [x] 多選為 AND:每個已選關鍵字都要在該幹員身上至少有一段命中敘述，不同關鍵字可以來自不同敘述
- [x] 分組由一份維護者清單決定;清單沒列到的關鍵字出現在「未分組」
- [x] 打字過濾關鍵字名稱;一鍵清除所有已選關鍵字
- [x] 術語官方定義在懸停或點開時顯示，定義裡的巢狀術語標記會被解析，不顯示原始標記
- [x] 命中敘述裡所有已選關鍵字都高亮
- [x] 「建置 → 查詢」測試涵蓋多關鍵字 AND 與未分組行為
