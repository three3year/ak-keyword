# 07 — 補充關鍵字

**What to build:** 面板上出現遊戲術語以外的補充關鍵字(擊退、拉拽、沉默、減速等)，點下去能找出敘述中以純文字提到它們的幹員。補充關鍵字的懸停定義由維護者撰寫，並標「非官方」。

**Blocked by:** 02 — 多關鍵字與面板

**Status:** resolved

- [x] 一份維護者清單記錄每個補充關鍵字的名稱、簡中與繁中比對字串、定義、分組;新增一個補充關鍵字只要改清單
- [x] 以純文字比對簡中字串(繁中字串供 08 使用);已在術語標記內的文字不重複計算
- [x] 補充關鍵字和術語一樣可以多選 AND、可以高亮、可以接受效果類型判定
- [x] 懸停定義標「非官方」
- [x] 初版清單至少包含擊退、拉拽、沉默、減速
- [x] 「建置 → 查詢」測試涵蓋純文字命中、術語標記內不重複計算
