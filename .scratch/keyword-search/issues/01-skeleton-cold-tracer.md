# 01 — 骨架與寒冷直通(陸服、技能)

**What to build:** 維護者在本機執行建置腳本，從陸服遊戲資料產出索引;打開網頁後看到所有術語組成的關鍵字清單(不分組)。點任一術語(例如寒冷)，就列出技能敘述裡含該術語的幹員名字與命中敘述。命中敘述裡關鍵字高亮、佔位符已換成實際數值，等級7與專精3兩個階段並列，並標出敘述來源(例如「技能2」)。這張票同時建立整個專案的「建置 → 查詢」測試接縫。規格見 `.scratch/keyword-search/spec.md`。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] Vue 3 + Vite + TypeScript 專案可以 `npm run dev` 在本機開啟、`npm run build` 打包成靜態檔、`npm run preview` 在本機預覽打包結果
- [x] 打包結果用相對的基底路徑，之後放到任何靜態主機(包括使用者自己部署的 GitHub Pages)都不必改設定
- [x] 建置腳本抓陸服 `zh_CN` 的幹員表、技能表與遊戲常數(術語字典)，產出索引 JSON;只收錄幹員，不收錄召喚物、陷阱
- [x] 敘述解析能處理巢狀標記、包住【】的術語標記、不是標記的角括號純文字(例如「<替身>」)，以及 `{key}`、`{key:0%}`、`{key:0.0}`、`{a@b:0%}`、`{x.y}` 等佔位符格式
- [x] 遇到無法辨識的標記或找不到數值的佔位符時，建置輸出警告(列出技能 id 與原文)
- [x] 技能取等級7與專精3兩個版本;沒有專精的技能只取其最高等級;任一階段命中就列出，並標出只在哪個階段出現
- [x] 查詢是純函式:索引 + 查詢條件 → 幹員清單與命中敘述
- [x] Vitest 測試走「建置 → 查詢」單一接縫:餵手寫的小型原始資料片段，建置後查詢，只斷言查詢結果;至少涵蓋上述解析情況與階段情況
- [x] Playwright 煙霧測試:打開打包後的網頁，點一個關鍵字，看到至少一筆結果
