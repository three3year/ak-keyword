# 08 — 台服與繁中

**What to build:** 玩家可以在陸服與台服之間切換，網頁會記住上次的選擇。台服模式只列台服已實裝的幹員，比對與顯示都用台服資料。陸服模式列出所有幹員，比對用陸服資料;台服同一段敘述內容一致時顯示台服官方繁中，否則顯示簡中。幹員名與關鍵字名優先用台服名稱。
