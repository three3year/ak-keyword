# 04 — 模組3 階段

**What to build:** 天賦與特性多了模組3 階段:每個模組各自取第3級改寫後的敘述參與比對，並與無模組階段並列顯示。命中敘述標出模組名;效果只在某個模組3 出現時，標「僅模組3(模組名)」，讓玩家知道要裝哪個模組才有效果。

**Blocked by:** 03 — 天賦與特性(無模組)

**Status:** ready-for-agent

- [ ] 建置讀國服模組清單與模組戰鬥資料，為每個模組產出第3級的特性與天賦敘述
- [ ] 多模組幹員的每個模組分開比對;任一模組命中即列出該幹員
- [ ] 命中敘述顯示模組名，無模組與模組3 並列;只在模組3 出現時標「僅模組3」
- [ ] 模組沒有改寫某段天賦或特性時，該段不重複列出模組版本
- [ ] 「建置 → 查詢」測試涵蓋:僅模組3 才有的效果、同一幹員兩個模組只有其一命中
