# 01 — 比對上游版本的指令

**What to build:** 維護者執行一個指令,就能知道國服、台服上游有沒有新的資料版本。指令只下載兩服上游含資料版號的那個檔,和目前索引裡的資料版本比對,印出每個伺服器的索引版號、上游版號,以及有沒有新版。兩服各自比較,彼此不比較;版號字串只要和索引不同就算有新版。比對本身寫成不連網的純函式:輸入索引版號和上游版號,輸出哪些伺服器有新版。指令的結束碼或輸出要讓 skill 能清楚分辨「有新版」和「已是最新」。

規格:[spec.md](../spec.md)(實作決策「比對上游版本」、測試決策「版號比對」)。

**Blocked by:** None — can start immediately
