# 02 — 已知警告清單

**What to build:** 建置索引時,維護者只會看到新的警告。維護者清單新增一份納入版控的已知警告清單(警告全文的列表,一開始是空的)。建置索引多讀這份清單,輸出除了全部警告,另外分出「新警告」(清單裡沒有的)和「已消失的已知警告」(清單裡有、這次沒出現的);比對用警告全文,一字不差才算同一則。建置指令除了現有的全部警告檔,另外寫出新警告與已消失警告,主控台摘要也分開列出數量。另外提供一個指令,把已知警告清單改成「目前全部警告」,讓維護者確認後一次接受,不用手抄警告全文。

台服的警告文字含有真正的換行,清單要能原樣保存多行文字。

規格:[spec.md](../spec.md)(實作決策「已知警告清單」「建置指令的輸出」「更新已知警告清單」,測試決策「建置索引這一層」)。

**Blocked by:** None — can start immediately
