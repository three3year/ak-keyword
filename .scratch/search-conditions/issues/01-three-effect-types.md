# 01 — 三種效果類型與一段多類型

**What to build:** 效果類型只剩施加、利用、反制,一段敘述對同一關鍵字可同時有多種。例:夜半 × 沉睡是施加也是利用,篩選列勾「利用」也找得到她。句型規則判定不出、又不在覆寫檔的配對沒有效果類型,不會成為命中敘述,並列在待複核清單。篩選列的效果類型勾選暫時保留,改為三種;結果卡的效果類型標籤顯示該段敘述所有符合的類型。規格見 `.scratch/search-conditions/spec.md`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 效果類型的值改為施加、利用、反制(識別字 `apply`、`exploit`、`counter`),移除抵抗與其他;介面標籤與淺色、深色模式的顏色跟著改
- [ ] 索引中每段文字的命中改為「關鍵字 → 效果類型清單」;判定不出時清單為空,文字中的關鍵字照樣高亮;重建索引
- [ ] 句型規則逐次出現判定,結果取聯集,不再取最強的一種;沒有句型命中的出現不貢獻類型
- [ ] 反制句型擴充:關鍵字後方緊接「(效果)失效」、前方有「無視」等;利用句型擴充:關鍵字後方緊接「後」(例如「閃避後」);簡中與繁中都要能判定
