# 04 — 類型鈕反灰

**What to build:** chip 上某個類型在目前伺服器沒有任何該關鍵字的敘述時,該類型鈕反灰、不能點(例:反制-暈眩 一個幹員都沒有)。只看關鍵字本身,不考慮星級、職業篩選或其他搜尋條件。切換伺服器後反灰跟著更新。規格見 `.scratch/search-conditions/spec.md`。

**Blocked by:** 03 — 搜尋條件 chip

**Status:** ready-for-agent

- [ ] 新增純函式:給定索引、伺服器與關鍵字,回傳該關鍵字在該伺服器下有資料的效果類型;伺服器可見性與查詢一致(台服模式只看台服文字與台服已實裝的幹員、模組、召喚物)
- [ ] chip 上沒有資料的類型鈕停用並變淡
- [ ] 「建置 → 查詢」測試:只回傳有資料的類型;某類型只有國服有時,台服模式下不回傳
- [ ] e2e:從實際資料挑一個有類型沒資料的關鍵字,確認該類型鈕停用
