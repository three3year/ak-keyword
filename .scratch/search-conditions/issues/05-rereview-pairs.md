# 05 — 重判舊「其他」與多類型配對

**What to build:** 舊判為「其他」的配對(扣掉 02 排除的術語),以及規則偵測到一段多類型的配對(約 98 個),由 session 內的 LLM 依三種效果類型的定義重判,寫回覆寫檔,讓它們重新出現在正確的搜尋條件下。LLM 判不出或有疑慮的配對整理成清單交給維護者決定。流程見 ADR 0001、0002;定義見 CONTEXT.md 的效果類型。規格見 `.scratch/search-conditions/spec.md`。

**Blocked by:** 01 — 三種效果類型與一段多類型;02 — 排除談不上效果類型的術語

**Status:** resolved

- [ ] 重建索引後,從待複核清單與規則結果找出上述兩類配對
- [ ] LLM 依定義判定(可多種),以複核寫回工具寫入覆寫檔;已知案例:因陀羅「閃避後攻擊力提升」含利用-閃避、銀灰「隱匿效果失效」為反制-隱匿、夜半 × 沉睡為施加與利用
