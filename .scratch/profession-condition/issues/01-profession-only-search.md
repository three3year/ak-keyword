# 01 — 只選職業也開始搜尋

**What to build:** 有搜尋條件或職業條件其中一種就開始搜尋。只點職業、不選關鍵字時，列出該職業的全部幹員:星級篩選照樣縮小，台服模式照樣略過台服未實裝的幹員，排序照舊(星級 → 職業 → 實裝新到舊)。這時結果卡只有卡頭(頭像、名稱與 PRTS 連結、星級、職業 · 分支),沒有分頁與敘述。只勾星級不開始搜尋。什麼都沒選時提示「點選關鍵字或職業開始搜尋」。無結果清單依職業 → 搜尋條件 → 伺服器 → 星級列出，沒有內容的項目不列。有搜尋條件時的行為完全不變。規格見 `.scratch/profession-condition/spec.md`。

**Blocked by:** None — can start immediately
