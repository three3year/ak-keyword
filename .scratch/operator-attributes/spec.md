# 規格:幹員詳情的屬性與勢力

Status: ready-for-agent

## 需要你決定的

### 陸服的勢力名稱表查不到某個勢力 ID 時怎麼辦?

台服查不到時已決定:報建置警告，顯示陸服的簡體名稱。陸服的名稱表是唯一來源，目前資料用到的勢力 ID 都查得到，這一題只管將來資料出現新 ID、名稱表卻還沒跟上的情況。

決定(2026-11-06):(a)報建置警告，畫面顯示勢力 ID。

### 「(+B)」的提示要照潛能加成的做法嗎?

本規格的「(+B)」寫法比照潛能加成，提示的做法卻不同:潛能加成用頁面共用的提示框(桌機懸停顯示、點擊釘住;觸控裝置點擊顯示),本規格原本寫成瀏覽器原生的 title(只有桌機懸停看得到)。

- (a)同潛能加成，用共用提示框顯示「信賴 100% 加成」(建議):手機點了也看得到，桌機與手機的行為和潛能加成一致;點擊會釘住提示框，Esc 照舊先關提示框。
- (b)與潛能加成不同，用原生 title:最簡單，但手機看不到，桌機的提示樣式也和潛能加成不一樣。

決定(2026-11-07):(a)同潛能加成，用共用提示框。

- (a)報建置警告，畫面顯示勢力 ID(例如 sees)(建議):和「術語字典沒有 X」同一套已知警告流程;畫面不會少一段，維護者看到警告再處理。
- (b)報建置警告，畫面略過這一層:畫面上沒有看不懂的英文 ID，但幹員的勢力會少一段，使用者不會察覺。

## 問題陳述

幹員詳情目前只有特性、天賦、技能的敘述。玩家想知道一位幹員練滿後的生命、攻擊、費用、阻擋數等屬性，或想知道他屬於哪個勢力時，得另外去 PRTS 或遊戲裡查。

## 解決方案

幹員詳情的卡頭、名字與星星那一塊的右邊，新增一欄屬性區塊:

- 第一行是階段說明，例如「精2 90級」;沒有精2 的幹員寫它能到的最高階段，例如「精1 55級」「精0 30級」。
- 第二排是費用、阻擋數、攻擊間隔、再部署時間。
- 第三排是生命、攻擊、防禦、法抗;生命、攻擊、防禦附上信賴加成，寫成「610(+50)」,滑鼠停在「(+50)」上(手機點一下)顯示「信賴 100% 加成」。加成為 0 的項目只寫數字。
- 之後一行所屬勢力，例如「炎-龍門 · 龍門近衛局」。
- 有隱藏勢力的幹員再一行隱藏勢力，例如「炎、維多利亞」。

屬性與勢力都跟著目前選的伺服器。台服的勢力名稱用本專案維護的繁中對照表。屬性區塊在幹員檔下載完才出現。手機寬度時整欄移到頭像那一列下面。

5. 身為玩家，我想看到再部署時間(例如 70s),規劃撤退後多久能再部署。

20. 身為陸服玩家，我想在陸服模式看到陸服的屬性與勢力，台服未實裝的幹員也一樣。

## 實作決策

- **名詞依 GLOSSARY.md:** 幹員詳情、幹員檔、屬性、信賴加成、勢力、隱藏勢力、伺服器、台服未實裝、潛能加成。
- **下載多一張表(只有陸服)。** 陸服多下載遊戲的勢力名稱表(`handbook_team_table`),提供勢力 ID → 名稱。台服的資料來源沒有這張表。
- **台服勢力名稱對照表。**
  - 本專案維護一份「勢力 ID → 繁中名稱」對照表，和補充關鍵字等維護資料放在一起;涵蓋台服資料目前用到的全部勢力 ID。
  - 建置時台服用到的勢力 ID 不在對照表裡:報建置警告(進已知警告流程),名稱改用陸服名稱表的簡體名稱。
  - 陸服名稱表也查不到的 ID:報建置警告(進已知警告流程),名稱用勢力 ID 本身。台服查不到、陸服也查不到時同樣如此。
- **建置取屬性。**
  - 取幹員最後一個階段、最後一個等級關鍵幀的生命、攻擊、防禦、法抗、費用、阻擋數、攻擊間隔、再部署時間。
  - 階段說明的資料:最後一個階段的編號(0、1、2)與它的滿級等級。
  - 信賴加成取信賴關鍵幀最後一格的生命、攻擊、防禦;其他欄位不看。
  - 不讀潛能與模組的屬性加成。
  - 阿米婭的近衛、醫療型態本來就是各自獨立的幹員，各取自己的資料。
- **建置取勢力。**
  - 勢力:國家、組織、團隊三個 ID,依此順序取有值的，空的略過。
  - 隱藏勢力:每一個都是同樣的三層 ID 組合，最多兩個。
  - 台服原始資料省略值為空的鍵，視同空。
- **幹員檔的形狀改變。**
  - 幹員檔多帶陸服與台服各自的屬性與勢力;台服未實裝的幹員只有陸服的。
  - 勢力在建置時就轉成名稱，幹員檔裡存的是兩服各自的名稱，不是 ID。
  - 索引不變。幹員檔形狀改變，需要重建。
- **查詢端「幹員詳情」的輸出多一個屬性部分。**
  - 依目前伺服器挑該服的屬性與勢力。
  - 輸出階段說明字串(例如「精2 90級」);費用、阻擋數、攻擊間隔、再部署時間;生命、攻擊、防禦各自的值與信賴加成(加成為 0 時沒有加成);法抗;所屬勢力字串;隱藏勢力字串。
  - 所屬勢力字串:各層名稱以「 · 」串起;三層都空時沒有所屬勢力。
  - 隱藏勢力字串:每個隱藏勢力照所屬勢力的方式串成一段，多段以「、」分隔;沒有時沒有隱藏勢力。
  - 攻擊間隔與再部署時間的數值不帶單位，由介面加「s」。
- **卡頭版面。**
  - 屬性區塊是卡頭裡獨立的一欄，位在名字、星星與職業那一塊的右邊、關閉鈕的左邊。
  - 由上到下:階段說明;費用、阻擋數、攻擊間隔、再部署時間;生命、攻擊、防禦、法抗;所屬勢力;隱藏勢力。各項以「標籤 值」呈現，標籤用:費用、阻擋數、攻擊間隔、再部署時間、生命、攻擊、防禦、法抗、所屬勢力、隱藏勢力。
  - 「(+B)」的樣式與提示做法同潛能加成:用頁面共用的提示框顯示「信賴 100% 加成」,桌機懸停顯示、點擊釘住，觸控裝置點擊顯示;Esc 照舊先關提示框。
  - 手機寬度(與幹員詳情全螢幕同一個斷點)時，整欄移到頭像那一列下面，佔滿寬度;勢力字串過長時換行，不得產生水平捲動。
  - 幹員檔下載完之前與下載失敗時不顯示屬性區塊;卡頭其他部分照舊立即顯示。
  - 結果卡的卡頭不變。
- **建立在 `name-detail-link` 之上。** 該規格已實作:幹員詳情的頭像是帶「↖」角標的 PRTS 連結，名字也是 PRTS 連結。屬性區塊不動頭像與名字，只在名字那一塊與關閉鈕之間插入一欄。

## 測試決策

- 好的測試只驗證外部行為:給定原始資料與伺服器，驗證查詢端公開函式的輸出，或使用者在頁面上看到的位置與內容。不驗證元件內部狀態或樣式類別。
- **建置 → 查詢(Vitest),以「幹員詳情」查詢函式為唯一接縫。**
  - 6★ 幹員:階段說明「精2 90級」,八項屬性取最後階段滿級值。
  - 3★ 幹員:「精1 55級」;1★ 幹員:「精0 30級」。
  - 阻擋數隨階段改變的幹員取最後階段的值。
  - 信賴加成:有加成的項目帶加成，加成為 0 的項目沒有加成;不含潛能加成。
  - 所屬勢力:有值的層依國家、組織、團隊順序以「 · 」串起，空的層略過。
  - 隱藏勢力:兩個隱藏勢力以「、」分隔、各自內部以「 · 」串起;沒有隱藏勢力時沒有這一項。
  - 伺服器:同一幹員兩服屬性或勢力不同時，各服輸出各自的值;台服名稱來自對照表。
  - 台服原始資料省略空鍵時照常輸出。
  - 台服勢力 ID 不在對照表:輸出簡體名稱，建置警告多一條。
  - 陸服勢力 ID 不在名稱表:輸出勢力 ID 本身，建置警告多一條。
  - 測試資料的幹員階段要補上屬性關鍵幀與信賴關鍵幀。
  - 先例:現有的幹員詳情、伺服器、警告的建置 → 查詢測試。
- **Playwright 煙霧測試(以實際索引執行)。**
  - 幹員詳情的屬性區塊在星星右側(左緣在星星右緣之右),含階段說明、八項屬性與所屬勢力。
  - 懸停「(+B)」時提示框顯示「信賴 100% 加成」;手機寬度點「(+B)」也顯示。
  - 攔住幹員檔下載時，卡頭顯示但沒有屬性區塊;放行後出現。
  - 手機寬度:屬性區塊在頭像下方，頁面與幹員詳情都沒有水平捲動。
  - 斷言的幹員與數值從索引與幹員檔推算或由測試自己造，不寫死會隨資料更新改變的數字。
- 屬性區塊在深色模式與桌機版面的觀感由人眼確認一次。

## 不在範圍內

- 召喚物的屬性。
- 潛能、模組帶來的屬性加成;各階段、各等級的屬性切換。
- 結果卡卡頭的任何改變。
- 以屬性或勢力搜尋、篩選、排序。
- 勢力的圖示、顏色、說明。
- 台服勢力名稱的自動轉換。
