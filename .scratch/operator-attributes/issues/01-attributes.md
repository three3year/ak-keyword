# 01: 幹員詳情顯示屬性

**What to build:** 打開幹員詳情、幹員檔下載完後，卡頭名字與星星那一塊的右邊出現屬性欄:一行階段說明(例如「精2 90級」),下面兩排屬性(費用、阻擋數、攻擊間隔、再部署時間;生命、攻擊、防禦、法抗),生命、攻擊、防禦附信賴加成「A(+B)」。屬性跟著目前選的伺服器。手機寬度時屬性欄移到頭像那一列下面。勢力不在這張票。規格見 `.scratch/operator-attributes/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 建置時從兩服原始資料取幹員最後一個階段、最後一個等級關鍵幀的八項屬性，以及信賴關鍵幀最後一格的生命、攻擊、防禦加成，寫進幹員檔;台服未實裝的幹員只有陸服的;不讀潛能與模組加成
- [ ] 「幹員詳情」查詢函式依目前伺服器輸出階段說明字串(「精2 90級」「精1 55級」「精0 30級」)與八項屬性;生命、攻擊、防禦各帶信賴加成，加成為 0 時沒有加成;攻擊間隔與再部署時間不帶單位
- [ ] 卡頭屬性欄位在名字、星星與職業那一塊的右邊、關閉鈕的左邊，由上到下:階段說明;費用、阻擋數、攻擊間隔、再部署時間;生命、攻擊、防禦、法抗;各項「標籤 值」,攻擊間隔與再部署時間加「s」
- [ ] 「(+B)」的樣式與提示做法同潛能加成:共用提示框顯示「信賴 100% 加成」,桌機懸停顯示、點擊釘住，觸控裝置點擊顯示;Esc 先關提示框
- [ ] 幹員檔下載完之前與下載失敗時不顯示屬性欄;卡頭其他部分照舊立即顯示
- [ ] 手機寬度(幹員詳情全螢幕的同一個斷點)時屬性欄移到頭像那一列下面、佔滿寬度，沒有水平捲動;結果卡卡頭不變
- [ ] Vitest(建置 → 查詢):6★ 精2 90級、3★ 精1 55級、1★ 精0 30級;阻擋數隨階段改變時取最後階段;信賴加成有值帶加成、為 0 沒有加成、不含潛能加成;兩服屬性不同時各輸出各自的值;測試資料補上屬性與信賴關鍵幀
- [ ] Playwright:屬性欄左緣在星星右緣之右，含階段說明與八項屬性;懸停「(+B)」提示框顯示「信賴 100% 加成」;攔住幹員檔下載時卡頭顯示但沒有屬性欄，放行後出現;手機寬度屬性欄在頭像下方、沒有水平捲動;斷言的數值從幹員檔推算或由測試自己造
- [ ] 重建資料(幹員檔形狀改變)
- [ ] 亮色、暗色與桌機版面下人工看過屬性欄
