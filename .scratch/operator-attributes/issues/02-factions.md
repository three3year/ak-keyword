# 02: 屬性欄顯示所屬勢力與隱藏勢力

**What to build:** 幹員詳情的屬性欄在兩排屬性下面多一行所屬勢力(例如「炎-龍門 · 龍門近衛局」),有隱藏勢力的幹員再多一行隱藏勢力(例如「炎、維多利亞」)。勢力跟著目前選的伺服器;陸服用遊戲的勢力名稱表，台服用本專案維護的繁中對照表。規格見 `.scratch/operator-attributes/spec.md`。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 陸服多下載勢力名稱表(`handbook_team_table`);台服不下載
- [ ] 新增台服「勢力 ID → 繁中名稱」對照表，和補充關鍵字等維護資料放在一起，涵蓋台服資料目前用到的全部勢力 ID(目前 44 個)
- [ ] 建置時取國家、組織、團隊三層有值的 ID 作勢力，隱藏勢力每個取同樣的三層組合;台服原始資料省略的空鍵視同空;轉成兩服各自的名稱寫進幹員檔，幹員檔存名稱不存 ID
- [ ] 台服勢力 ID 不在對照表:報建置警告，名稱用陸服簡體名稱;陸服名稱表也查不到(不論哪一服):報建置警告，名稱用勢力 ID 本身
- [ ] 「幹員詳情」查詢函式依目前伺服器輸出所屬勢力字串(各層以「 · 」串起，三層都空時沒有)與隱藏勢力字串(每個照所屬勢力串成一段、多段以「、」分隔，沒有時沒有)
- [ ] 屬性欄在兩排屬性之後依序加「所屬勢力 …」「隱藏勢力 …」;沒有的那一行不顯示;字串過長時換行，手機寬度沒有水平捲動
- [ ] Vitest(建置 → 查詢):有值的層依序串起、空層略過;兩個隱藏勢力以「、」分隔;沒有隱藏勢力時沒有這一項;兩服勢力不同時各輸出各自的;台服名稱來自對照表;台服省略空鍵照常輸出;台服 ID 不在對照表輸出簡體名稱且警告多一條;陸服 ID 不在名稱表輸出 ID 且警告多一條
- [ ] Playwright:屬性欄有所屬勢力那一行;有隱藏勢力的幹員有隱藏勢力那一行，沒有的幹員沒有;斷言的幹員與字串從幹員檔推算或由測試自己造
- [ ] 重建資料，正式資料沒有新的勢力警告
