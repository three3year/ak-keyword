# 02 — 幹員詳情頁籤展開與召喚物歸屬

**What to build:** 幹員詳情的頁籤一層展開，每段敘述一個頁籤:「特性|天賦1|天賦2|(模組新增的天賦)|技能1|技能2|技能3」,打開時預設停在特性。召喚物不再排在每頁最後，而是接在帶出它的那一頁下方:技能召喚的接在那個技能頁，天賦帶出的接在那個天賦頁；一個召喚物的天賦與技能放在一起，依序是召喚物天賦、召喚物技能，標出召喚物名稱。建置要記錄每個召喚物由哪些技能或哪個天賦帶出。規格見 `.scratch/operator-detail-tweaks/spec.md`。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 建置為每個召喚物記錄帶出它的來源:召喚它的技能編號(可能不只一個),或帶出它的天賦編號；幹員檔與索引都帶，重建資料
- [x] 對應不到技能或天賦的召喚物發建置警告，接在最後一個頁籤下方
- [x] 「幹員詳情」輸出:幹員本身每段敘述一個分頁，依序特性、天賦、技能，標籤是敘述來源字串；每個分頁第一段是幹員本身那段，之後是它帶出的召喚物的天賦與技能
- [x] 預設分頁是特性；沒有技能的幹員沒有技能分頁
- [x] 每段的階段、預設階段、命中與高亮規則不變；同一段召喚物敘述完全相同時照舊合併
- [x] 介面照新的分頁顯示，頁籤放不下時自動換行
- [x] Vitest 建置 → 查詢:分頁順序與標籤、預設特性、技能召喚物只在召喚它的技能分頁(召喚物天賦在召喚物技能之前)、被兩個技能召喚時兩個分頁都有、天賦帶出的召喚物在天賦分頁(含沒有技能的幹員)
