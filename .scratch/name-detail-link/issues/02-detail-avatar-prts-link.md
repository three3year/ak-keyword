# 02: 幹員詳情的頭像連到 PRTS

**What to build:** 幹員詳情的頭像比照詳情名字,點了在新分頁打開 PRTS 的該幹員頁;左上角加 ↖ 角標,手機上也看得出能點。詳情名字維持現狀。規格見 `.scratch/name-detail-link/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 詳情頭像包成連結:網址、新分頁開啟、不帶來源資訊也不讓新頁控制本頁、滑鼠提示文字「在 PRTS 查看X(新分頁)」都和詳情名字相同
- [x] 頭像連結的無障礙名稱是「在 PRTS 查看X(新分頁)」
- [x] 左上角加 ↖ 角標,位置、大小、顏色比照結果卡頭像的「i」;螢幕閱讀器不念角標
- [x] 滑過時頭像變亮、角標變強調色;鍵盤聚焦時角標變強調色
- [x] 詳情名字的外觀與行為不變
- [x] e2e:詳情的名字與頭像都連到 PRTS 該幹員頁(陸服名經網址編碼)、在新分頁開啟、帶 noopener 與 noreferrer;切到台服後網址仍是陸服名
- [ ] 亮色、暗色下人工看過角標與滑過外觀
