# 01: 結果卡名稱打開幹員詳情

**What to build:** 大卡與小卡上的幹員名稱不再是 PRTS 連結,改成和頭像一樣點了打開幹員詳情。名稱平時看起來就是一般文字,滑過或鍵盤聚焦時才變強調色加底線;滑過名稱或頭像時兩者一起有反應。規格見 `.scratch/name-detail-link/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 名稱改成標題裡的按鈕,標題結構不變;點了打開該幹員的幹員詳情,關閉後焦點回到名稱(和頭像同一套打開與焦點歸還機制)
- [ ] 大卡、小卡都改;台服未實裝的小卡裡名稱照舊隨文字區壓灰
- [ ] 名稱按鈕的無障礙名稱是幹員名字,滑鼠提示文字是「檢視X的詳情」;頭像按鈕不變,找「檢視X的詳情」按鈕時只找得到頭像
- [ ] 名稱平時:一般文字色、沒有底線、沒有按鈕預設外觀;滑過或鍵盤聚焦:強調色加底線,游標是手指
- [ ] 滑過名稱或頭像任一個時,名稱呈現滑過樣式、頭像變亮且「i」變強調色;只連動滑過,鍵盤聚焦各自顯示
- [ ] 原本兩處名稱共用的連結樣式改成只套在幹員詳情的名字上,詳情名字外觀不變
- [ ] 結果卡上沒有任何連結
- [ ] e2e:刪掉「幹員名稱是連到 PRTS 的新分頁連結,頭像是按鈕不是連結」;新增:大卡點名稱打開幹員詳情、關閉後焦點回到名稱按鈕;小卡(只選職業條件)點名稱打開幹員詳情;結果卡上找不到連結
- [ ] 亮色、暗色下人工看過名稱的平時與滑過外觀、滑過連動
