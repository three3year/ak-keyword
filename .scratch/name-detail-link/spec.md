# 規格:結果卡名稱打開幹員詳情,PRTS 連結移到幹員詳情

Status: ready-for-agent

## 需要你決定的

### 詳情頭像連結的無障礙名稱用什麼?

決定(2026-11-06):(a),無障礙名稱是「在 PRTS 查看X(新分頁)」。

頭像圖片的替代文字是空的,包成連結後要另給一個無障礙名稱,不然螢幕閱讀器只會念「連結」。詳情名字(參照實作)的無障礙名稱就是幹員名字本身。

- (a)「在 PRTS 查看X(新分頁)」,和滑鼠提示文字相同(建議):說得出點了會做什麼;做法和結果卡頭像相同(結果卡頭像的無障礙名稱就是動作描述「檢視X的詳情」)。與詳情名字不同。
- (b)幹員名字,同詳情名字:對話框裡會有兩個同名連結,螢幕閱讀器使用者分不出差別。

## 問題陳述

結果卡上的幹員名稱現在是連到 PRTS 的連結。玩家在結果卡上最想點的是名稱,但點了就跳出本站、開一個新分頁,想看幹員全部敘述反而只能點頭像。名稱平時就是強調色加底線,整張卡看起來像一列外部連結。

## 解決方案

- **結果卡名稱打開幹員詳情。** 大卡、小卡的名稱都改成和頭像一樣,點了打開幹員詳情;結果卡上不再有 PRTS 連結。
- **名稱平時是一般文字,滑過才有變化。** 平時用一般文字色、沒有底線;滑過或鍵盤聚焦時變強調色加底線。滑過名稱時頭像也一起有反應,滑過頭像時名稱也一起有反應。
- **PRTS 連結在幹員詳情裡。** 詳情的名字照舊連到 PRTS;詳情的頭像也改成連到 PRTS,左上角加一個 ↖ 角標提示能點。

## 實作決策

- **名詞依 GLOSSARY.md:** 結果卡、大卡、小卡、幹員詳情。GLOSSARY 的「幹員詳情」已改成「點結果卡的幹員頭像或名稱打開」。
- **資料與查詢不變。** 查詢結果本來就帶完整的 PRTS 網址;這次只改介面,不重建索引。
- **結果卡名稱改成按鈕**(參照實作:結果卡頭像)。
  - 名稱按鈕放在原本的標題裡,標題結構不變。
  - 點了打開幹員詳情,同頭像:回報點擊的元素,關閉詳情後焦點回到該元素。
  - 大卡、小卡都改,同頭像。
  - 無障礙名稱是幹員名字本身;「檢視X的詳情」放在滑鼠提示文字。與頭像不同:頭像的無障礙名稱是「檢視X的詳情」、沒有滑鼠提示文字。這樣找「檢視X的詳情」按鈕時只會找到頭像,用標題名稱找卡片的方式也照舊。
  - 沒有「i」角標。與頭像不同:頭像有「i」,名稱用文字的變化提示。
  - Tab 會停在名稱和頭像兩處,同頭像。
  - 台服未實裝的小卡裡,名稱隨文字區一起壓灰,同現狀。
- **結果卡名稱的外觀。**
  - 平時:一般文字色、沒有底線,去掉按鈕預設外觀。
  - 滑過或鍵盤聚焦:強調色加底線,游標是手指。與頭像不同:頭像滑過是變亮、「i」變強調色。
  - 滑過連動:滑過名稱或頭像任一個,名稱與頭像同時呈現各自的滑過樣式。只連動滑過;鍵盤聚焦各自顯示。
- **詳情頭像改成 PRTS 連結**(參照實作:詳情名字)。
  - 網址、新分頁開啟、不帶來源資訊也不讓新頁控制本頁、滑鼠提示文字「在 PRTS 查看X(新分頁)」,同詳情名字。
  - 無障礙名稱是「在 PRTS 查看X(新分頁)」,和滑鼠提示文字相同。與詳情名字不同:詳情名字的無障礙名稱是幹員名字;見[需要你決定的](#需要你決定的)。
  - 左上角加 ↖ 角標,位置、大小、顏色比照結果卡頭像的「i」;滑過或鍵盤聚焦時角標變強調色、滑過時頭像變亮。與詳情名字不同:詳情名字是滑過時底線加深。
  - 角標只是視覺提示,螢幕閱讀器不念。
- **詳情名字維持現狀**:強調色加淡底線,滑過時底線加深。原本兩處名稱共用的連結樣式改成只套在詳情名字上。

## 測試決策

- **只在 e2e 這一層測。** 這次只改介面,沒有查詢或建置的行為變化,不加單元測試。
- **好的測試從使用者看得到的地方驗證:** 用角色與名稱找元素,驗證點了打開什麼、連結的網址與開啟方式;不檢查 class 名稱或樣式細節,也不真的連到 PRTS。
- **刪掉**現有那條「幹員名稱是連到 PRTS 的新分頁連結,頭像是按鈕不是連結」,由下面兩條取代。
- **結果卡名稱打開幹員詳情:**
  - 大卡點名稱,打開該幹員的幹員詳情;關閉後焦點回到名稱按鈕。
  - 小卡(只選職業條件)點名稱,同樣打開幹員詳情。
  - 結果卡上找不到任何連結。
- **詳情的名字與頭像都連到 PRTS:**
  - 兩者網址都是 PRTS 該幹員頁(陸服名經網址編碼)、在新分頁開啟、帶 noopener 與 noreferrer。
  - 切到台服後,網址仍是陸服名。
- **不寫 e2e:** 名稱與頭像的滑過連動、平時與滑過的外觀、↖ 角標的樣子,交給人工看。
- **前例:** 現有的 PRTS 連結 e2e 驗證網址開頭與開啟方式;幹員詳情的 e2e 驗證打開與關閉後焦點回到觸發元素。

## 不做的事

- 結果卡頭像的行為與外觀,除了滑過時和名稱連動以外,都不變。
- 不改 PRTS 網址的產生規則(陸服名、同名幹員的對照)。
- 詳情名字的外觀與行為不變。
- 不在結果卡上另外保留 PRTS 的入口。
