# 規格:幹員詳情與技能圖示、技力

Status: ready-for-agent

## 需要你決定的

### 幹員詳情要不要顯示效果類型標籤?

決定(2026-10-20):顯示，只在命中目前搜尋條件的階段，規則和結果卡相同。

結果卡在內容區顯示命中的效果類型(例如「施加」)。這次討論沒有決定幹員詳情要不要也顯示。

- (a)顯示(建議):只在目前搜尋條件命中的階段顯示，規則和結果卡相同。兩邊一致，能一眼看出哪段命中。
- (b)不顯示:詳情只靠關鍵字高亮標出命中。版面較乾淨，但要自己找命中的那句。

## 問題陳述

結果卡只列出命中搜尋條件的敘述。玩家想了解一位幹員的整體能力，例如其他技能做什麼、天賦是什麼、特性怎麼寫，就得離開網站去 PRTS 查。結果卡也看不到技能圖示和技力，看不出技能是自動回復還是攻擊回復，要多少技力才能發動，而這正是比較幹員時常看的資訊。

## 解決方案

- **幹員詳情。** 點結果卡上的幹員頭像，打開幹員詳情，列出這位幹員全部的特性、天賦與技能，包括召喚物的。
  - 頭像右上角常駐一個小圓形「i」標記，一眼就看得出可以點。幹員名稱照舊連到 PRTS。
  - 桌機上是置中對話框，背景變暗；手機上占滿螢幕。點外面、按 Esc、按關閉鈕，或在手機上按返回鍵，都會關閉。
  - 標題區顯示頭像、名稱、星級、職業與分支、PRTS 連結。
  - 分頁依序是「特性|天賦|技能」，預設停在技能頁。沒有技能的幹員(1–2★)不顯示技能頁，預設停在天賦頁。
  - 每頁由上到下列出該敘述來源的全部敘述，召喚物的敘述接在最後。每段各有自己的階段切換，一開始停在最低階段。
  - 目前搜尋條件命中的關鍵字照樣高亮。所有關鍵字都能懸停或點擊查看定義，但點擊不會改變搜尋條件。
- **技能圖示與技力。** 結果卡與幹員詳情的技能都顯示技能圖示。
  - 圖示放在左邊，疊上技力:播放鍵、初始技力、回復類型圖示、所需技力。
  - 右邊由上而下是階段切換、技能名稱。幹員詳情在名稱下面再多一行文字欄位，例如「自動回復・自動觸發・初始技力 0・所需技力 100・持續 25 秒」。
  - 切換階段時，技力跟著換成該階段的數值。
- **資料。** 開頁時下載的資料量不變。每位幹員的完整敘述各存成一個檔，打開這位幹員的詳情時才下載。技能圖示也是畫面上出現時才下載。

## 實作決策

- **名詞依 CONTEXT.md:** 結果卡、幹員詳情、技力(初始技力、所需技力)、回復類型、觸發方式。
- **技能的新資料(建置時從 skill_table 讀取)。**
  - 每個技能階段多帶:回復類型(自動回復、攻擊回復、受擊回復，或沒有)、觸發方式(手動觸發、自動觸發、被動)、初始技力、所需技力、持續時間、是否為彈藥技能、充能次數。
  - 來源欄位:回復類型來自 spType，數值 8 視為「沒有回復類型」(被動與部分召喚物技能);觸發方式來自 skillType;彈藥來自 durationType 的 AMMO;充能次數來自 maxChargeTime。
  - 持續時間只在大於 0 時顯示。負值與 0 都不顯示，資料裡有大量負值代表「沒有固定持續時間」。
  - 台服的 skill_table 也有這些欄位，各伺服器各用自己的數值。
- **技能圖示。**
  - 檔名取 iconId，沒有時改用 skillId。台服 skill_table 沒有 iconId，一律用陸服的 iconId(兩服的 skillId 相同)。
  - 建置時從頭像所在的資料來源下載圖示，沿用頭像的下載、快取、縮圖、轉 webp 流程，存進網站的靜態檔。邊長取詳情最大顯示尺寸的兩倍左右。已存在就跳過。
  - 只下載索引內幹員與召喚物的技能圖示。
  - 缺圖時發警告，該技能改用預留圖。
- **索引(查詢端的搜尋資料)。**
  - 技能類的命中敘述多帶技能圖示路徑，每個技能階段多帶上述技力欄位，供結果卡使用。
  - 其他內容不變。開頁時下載的仍只有這份索引。
- **幹員檔(新增，每位幹員一個)。**
  - 包含這位幹員全部的特性、天賦、技能敘述，召喚物的天賦、技能也算在內。不論有沒有關鍵字命中都收錄。
  - 每段敘述的階段、各伺服器文字、效果類型資訊，以及「陸服資料」「不存在的階段」等規則，都和索引裡的命中敘述相同。技能另帶圖示與各階段的技力欄位。
  - 建置與索引一起產生。檔案位置包含這次建置的識別，網站更新後不會讀到和索引不同版本的幹員檔。
  - 索引裡每位幹員帶有指向自己幹員檔的資訊。
  - 只存在陸服的幹員，幹員檔只有陸服資料。
- **查詢端新增公開函式「幹員詳情」。**
  - 輸入:幹員檔、伺服器、目前的搜尋條件。
  - 輸出:
    - 分頁清單:依序是特性、天賦、技能，沒有內容的分頁省略。另帶預設分頁:有技能頁時是技能頁，否則是天賦頁。
    - 每個分頁的敘述清單:幹員本身的敘述在前，召喚物的在後。每段帶敘述來源字串(例如「天賦3」「召喚物技能1」)、技能或天賦名、召喚物名。
    - 每段的階段清單:標籤規則和結果卡相同。每個階段帶是否存在、是否命中目前搜尋條件、命中的效果類型、文字(命中的關鍵字已標好高亮)、模組全名、「陸服資料」旗標，技能另帶技力欄位。
    - 預設階段:第一個存在的階段，不看命中。
  - 結果卡的查詢函式維持既有輸出，只多帶上述技能圖示與技力欄位。
- **結果卡。**
  - 頭像改成按鈕，無障礙名稱是「檢視<幹員名>的詳情」。右上角常駐小圓形「i」標記，懸停時頭像微亮、游標變成手指。幹員名稱連結不變。
  - 技能分頁的版面:
    - 左邊是約 44px 的技能圖示，高度對齊右邊兩列:上列是階段切換，下列是技能名稱與標籤。只有一個階段時沒有階段切換，圖示照樣在左。
    - 疊字在圖示下緣靠右，依序是:播放鍵、初始技力、回復類型圖示、所需技力。
    - 回復類型圖示以三種形狀或顏色區分，有懸停文字說明；疊字整體帶完整的無障礙文字。
    - 沒有回復類型的技能(被動等)不疊字。
  - 天賦、特性分頁版面不變。
- **幹員詳情(介面)。**
  - 版面:
    - 對話框角色，有標題。桌機置中、背景變暗；窄螢幕占滿螢幕。
    - 打開時焦點移入對話框，關閉後焦點回到觸發的頭像。
    - 標題區直接用索引裡的資料，打開瞬間就顯示。
  - 載入與快取:
    - 內容區在幹員檔下載完之前顯示「載入中」，下載失敗時顯示錯誤訊息與重試鈕。
    - 已下載的幹員檔在這次瀏覽期間留在記憶體，重開不必再下載。
  - 分頁與技能頭部:
    - 分頁以分頁角色標記，用法同結果卡。
    - 技能頭部:左邊是和結果卡相同的疊字圖示，右邊由上而下是階段切換、技能名稱、文字欄位。
    - 文字欄位以「・」分隔，依序是:回復類型、觸發方式、初始技力 N、所需技力 N、持續 N 秒(大於 0 才有)、充能 N 次(大於 1 才有)、彈藥(彈藥技能才有)。被動技能只寫「被動」。
  - 內容區顯示效果類型標籤，只標在命中目前搜尋條件的階段，規則和結果卡相同。
  - 各段的目前階段只存在這次打開的詳情裡，關閉後重開回到預設。
  - 關鍵字互動:
    - 懸停、點擊、觸控都顯示定義提示框，提示框顯示在對話框之上。
    - 點擊不切換搜尋條件。潛能加成提示照舊。
  - 關閉方式:
    - 關閉鈕、Esc、點背景都能關閉。
    - 打開時加一筆瀏覽紀錄，網址內容不變；按返回鍵關閉詳情。用其他方式關閉時，也收回這筆紀錄，不留多餘的返回步驟。
- **頁尾。** 「頭像」資料來源連結的標籤改為「頭像與圖示」，連結和懸停說明不變。

## 測試決策

- 好的測試只驗證外部行為:給定原始資料與查詢條件，驗證查詢端公開函式的輸出，或使用者在頁面上看到、能操作的內容。不驗證元件內部狀態或樣式類別。
- **建置 → 查詢(Vitest)。** 沿用手寫原始資料片段與既有的 fixture 輔助函式，對建置輸出跑查詢端公開函式。
  - 幹員詳情:
    - 分頁依序是特性、天賦、技能。沒有技能的幹員沒有技能頁，預設分頁是天賦。
    - 沒有關鍵字命中的技能、天賦、特性也會列出。
    - 召喚物的天賦與技能排在同一頁最後，並帶召喚物名。
    - 模組新增的天賦:無模組階段不存在，預設階段是第一個模組3。
    - 預設階段是最低的存在階段，即使只有專精3 命中，也停在等級7。
    - 命中目前搜尋條件的階段有高亮、命中旗標與效果類型；沒有搜尋條件時都沒有。
    - 台服:用台服文字，台服沒有的模組階段帶「陸服資料」旗標。
  - 技力欄位:
    - 回復類型、觸發方式、初始技力、所需技力對應正確。
    - 持續時間只在大於 0 時出現，充能次數只在大於 1 時出現。
    - 彈藥技能帶彈藥旗標；被動技能沒有回復類型與技力。
    - 等級7 與專精3 的技力各自正確。
  - 技能圖示:
    - 有 iconId 時用 iconId，沒有時用 skillId。
    - 台服沿用陸服的 iconId。
  - 結果卡的查詢結果:技能類命中敘述帶圖示與各階段技力，其他輸出不變。
  - 先例:技能、天賦、模組、召喚物、伺服器的現有建置 → 查詢測試。
- **Playwright 煙霧測試(以實際索引執行)。**
  - 點結果卡頭像打開幹員詳情，看到標題區與「特性|天賦|技能」分頁，預設在技能頁，且技能頁的技能數和該幹員實際技能數相同。
  - 技能頭部有圖示與文字欄位。切換專精3 後，文字或技力會變。
  - 沒有技能的幹員打開後沒有技能頁。
  - Esc、關閉鈕、返回鍵都能關閉，關閉後仍在原本的結果列表。
  - 結果卡的技能分頁有技能圖示。
  - 頁尾的「頭像與圖示」連結:同步改寫既有的頁尾斷言。
  - 手機寬度測試補上「打開詳情後整頁沒有水平捲動」。
  - 實作者從實際資料挑出符合條件的幹員與關鍵字。
- 技能圖示的下載轉檔沿用頭像做法，不寫自動測試。疊字樣式、「i」標記、深色模式由人眼確認一次。
- 不新增元件層級的單元測試。

## 不在範圍內

- 幹員詳情顯示模組本身(模組名稱以外的模組屬性加成、模組任務)、基建技能、數值面板、潛能與信賴加成表、攻擊範圍。
- 天賦與特性的圖示(遊戲裡沒有)。
- 從幹員詳情直接切換到其他幹員(上一位、下一位)。
- 幹員詳情的網址分享，或重新整理後還停在詳情。
- 在詳情裡點關鍵字加入或移除搜尋條件。
- 詳情裡記住各段的階段，跨越關閉與重開。
- 搜尋、排序、篩選、命中判定規則的任何改變。
