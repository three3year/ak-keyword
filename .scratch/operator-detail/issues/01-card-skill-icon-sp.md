# 01 — 結果卡的技能圖示與技力疊字

**What to build:** 結果卡的技能分頁顯示技能圖示，圖示下緣靠右疊上技力。版面改成:左邊約 44px 的技能圖示，右邊上列是階段切換、下列是技能名稱與標籤。疊字依序是播放鍵、初始技力、回復類型圖示、所需技力，切換階段時跟著換成該階段的數值。被動技能(沒有回復類型)只顯示圖示、不疊字。只有一個階段的技能沒有階段按鈕，圖示照樣在左。建置時讀入技能的技力欄位與圖示 id，從頭像所在的資料來源下載圖示並轉檔。頁尾「頭像」連結的標籤改成「頭像與圖示」。規格見 `.scratch/operator-detail/spec.md`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
