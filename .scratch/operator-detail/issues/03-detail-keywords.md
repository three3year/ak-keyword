# 03 — 幹員詳情裡的關鍵字

**What to build:** 幹員詳情的文字和結果卡一樣，把目前搜尋條件命中的關鍵字高亮，並在命中的階段顯示效果類型標籤。所有術語與補充關鍵字都能懸停、點擊或觸控看定義，但點擊不會改變搜尋條件，背後的結果列表不會變。天賦的潛能加成提示照舊。提示框顯示在對話框之上。規格見 `.scratch/operator-detail/spec.md`。

**Blocked by:** 02 — 幹員詳情對話框

**Status:** ready-for-agent

- [x] 「幹員詳情」查詢輸出中，命中搜尋條件的階段帶命中旗標、命中的效果類型，文字裡命中的關鍵字已標好高亮；沒有搜尋條件時都沒有
- [x] 詳情內容區只在命中的階段顯示效果類型標籤，規則和結果卡相同
- [x] 詳情裡的關鍵字懸停、點擊、觸控都顯示定義提示框，提示框在對話框之上，不被遮住
- [x] 詳情裡點關鍵字不新增、也不移除搜尋條件
- [x] 潛能加成提示在詳情裡照常運作
- [x] Vitest 建置 → 查詢:命中階段有高亮、命中旗標與效果類型，未命中的階段沒有；沒有搜尋條件時全部沒有
- [x] Playwright:搜尋一個關鍵字後打開命中幹員的詳情，詳情裡有高亮；點詳情裡的關鍵字，關閉後搜尋條件與結果數不變
