# 02 — 幹員詳情對話框

**What to build:** 點結果卡上的幹員頭像打開幹員詳情，列出這位幹員全部的特性、天賦、技能，包括召喚物的，不限命中敘述。頭像改成按鈕，右上角常駐小圓形「i」標記；游標移上去時頭像微亮、變手指。桌機上是置中對話框，背景變暗。標題區顯示頭像、名稱、星級、職業與分支、PRTS 連結。分頁依序是「特性|天賦|技能」，預設停在技能頁；沒有技能的幹員沒有技能頁，預設停在天賦頁。每頁由上到下列出各段敘述，召喚物的接在最後；每段各自切換階段，一開始停在最低的存在階段。幹員檔下載中時顯示「載入中」，失敗時顯示錯誤與重試鈕。按關閉鈕、Esc 或點背景都能關閉。本票的詳情文字先不處理高亮與關鍵字提示(見 03)，技能頭部也先只有名稱(見 04)。規格見 `.scratch/operator-detail/spec.md`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 建置為每位幹員產生一個幹員檔，收錄全部特性、天賦、技能(含召喚物)。階段、各伺服器文字、效果類型、「陸服資料」與不存在階段的規則，都和索引的命中敘述相同
- [x] 幹員檔的位置包含這次建置的識別；索引裡每位幹員帶有指向自己幹員檔的資訊
- [x] 查詢端新增公開函式「幹員詳情」:輸入幹員檔、伺服器、搜尋條件，輸出分頁清單與預設分頁、各頁敘述清單(敘述來源字串、名稱、召喚物名)、各段階段清單(標籤、是否存在、模組全名、陸服資料旗標、文字)與預設階段
- [x] 頭像是按鈕，無障礙名稱「檢視<幹員名>的詳情」，可用 Tab 聚焦、按 Enter 打開；右上角常駐「i」標記；幹員名稱照舊連到 PRTS
- [x] 只用職業篩選、沒有命中敘述的結果卡也能打開詳情
- [x] 對話框有對話框角色與標題；標題區在打開的瞬間就顯示(用索引資料)
- [x] 分頁以分頁角色標記；所有存在的階段都能切換，不存在的無模組階段變淡、不能點
- [x] 各段的目前階段只存在這次打開的詳情裡，重開回到預設；關閉後結果列表的捲動位置與各卡狀態不變
- [x] 載入中、下載失敗與重試都能運作；同一次瀏覽中重開同一位幹員不再下載
- [x] 台服顯示台服文字，台服沒有的模組階段顯示陸服文字並標「陸服資料」
- [x] Vitest 建置 → 查詢:分頁順序與省略、未命中的敘述也列出、召喚物排在最後、模組新增天賦的預設階段、預設最低階段(只有專精3 命中時仍停在等級7)、台服與陸服資料
- [x] Playwright:點頭像打開詳情，預設在技能頁，技能數和該幹員實際技能數相同；沒有技能的幹員沒有技能頁；Esc、關閉鈕都能關閉
