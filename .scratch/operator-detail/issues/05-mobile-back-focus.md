# 05 — 手機全螢幕、返回鍵關閉與焦點管理

**What to build:** 窄螢幕上，幹員詳情占滿整個螢幕。打開詳情時加一筆瀏覽紀錄(網址內容不變)，按瀏覽器或系統的返回鍵就關閉詳情、停在原本的結果列表，不會離開網站或丟掉搜尋條件。用關閉鈕、Esc 或點背景關閉時，也收回這筆紀錄，不留多餘的返回步驟。打開時焦點移入對話框，關閉後回到觸發的頭像。規格見 `.scratch/operator-detail/spec.md`。

**Blocked by:** 02 — 幹員詳情對話框

**Status:** ready-for-agent

- [x] 窄螢幕上詳情占滿螢幕；桌機版面不變
- [x] 按返回鍵關閉詳情，搜尋條件、結果列表、捲動位置都不變
- [x] 用其他方式關閉後，再按一次返回鍵會照常離開或回到上一頁，不會停在一筆多餘的紀錄
- [x] 打開時焦點在對話框內，關閉後焦點回到原本的頭像按鈕
