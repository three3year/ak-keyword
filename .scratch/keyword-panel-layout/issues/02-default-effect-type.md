# 02 — 面板點關鍵字時預設亮第一個有資料的效果類型

**What to build:** 在關鍵字面板點一個未選的關鍵字時,新的搜尋條件 chip 不再一律亮「施加」,而是依目前伺服器有資料的效果類型,照施加 → 利用 → 反制的順序亮第一個。例如國服點「異常狀態」亮利用,點「暈眩」照舊亮施加。之後切換伺服器,已經加入的 chip 不變。規格見 `.scratch/keyword-panel-layout/spec.md`。

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] 查詢模組新增預設效果類型函式:給定索引、伺服器與關鍵字,回傳該伺服器有資料的類型中依施加、利用、反制順序的第一個;都沒有時回傳施加
- [ ] 面板點選未選的關鍵字時,用這個函式決定 chip 一開始亮哪一顆類型鈕
- [ ] 切換伺服器時既有 chip 的類型鈕不變
- [ ] Vitest:有施加回傳施加;只有利用與反制回傳利用;只有反制回傳反制;某類型只有國服有時,台服回傳下一個有資料的類型
- [ ] e2e:點「異常狀態」後 chip 預設亮利用;點「暈眩」照舊亮施加
