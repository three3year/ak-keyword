# 04 — 關鍵字面板依新排列分組、分行

**What to build:** 關鍵字面板照規格裡的表格排列:控場、減益、增益、元素傷害各分成固定的幾行,每行從新的一行開始,行內放不下時折行;沉默、失重移到減益;推、拉、減速、閃避等補充關鍵字和術語交錯排列。機制、傷害、未分組維持現有內容與順序,各為一行。台服隱藏關鍵字後變空的行不佔位。桌機側欄與手機抽屜一致,手機寬度沒有水平捲動。規格見 `.scratch/keyword-panel-layout/spec.md`(「解決方案」一節的表格)。

**Blocked by:** 03 — 隱藏目前伺服器沒有幹員的關鍵字

**Status:** ready-for-agent

- [ ] 維護者清單每組改由多行組成,每行是一串關鍵字代號;術語與補充關鍵字(`sup.` 代號)都能排進任何一行,順序就是面板順序
- [ ] 清單依規格表格排好控場、減益、增益、元素傷害;機制維持現有順序為一行;新增「傷害」組(真實傷害)排在機制之後
- [ ] 補充關鍵字不再自帶分組欄位,分組只由維護者清單決定;清單沒列到的術語或補充關鍵字歸到「未分組」,排在最後一組,為一行
- [ ] 索引帶出分組、每組的行與每行關鍵字的順序,取代術語在先、補充在後的排序
- [ ] 面板分組函式回傳「分組 → 行 → 關鍵字」,保留 03 的伺服器隱藏;變空的行與分組不回傳
- [ ] 面板每一行從新的一行開始,行內放不下時折行
- [ ] Vitest:依清單的分組、行與順序回傳,術語與補充關鍵字可以交錯;清單沒列到的歸到未分組;整行被拿掉時不回傳空行
- [ ] e2e:控場第一行以減速開頭;沉默與失重在減益
- [ ] e2e:手機寬度測試照舊確認整頁沒有水平捲動
