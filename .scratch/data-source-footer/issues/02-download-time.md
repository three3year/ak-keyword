# 02 — 各伺服器資料版本的下載時間

**What to build:** 頁尾每個伺服器的版號後面,接上該服資料的下載時間,一律以台灣時間顯示到分,例如「國服 78.2.0 · 2026-10-19 12:14(UTC+8)」。線上建置自動記下各服資料的下載時間;離線建置沿用快取當初的下載時間,不會讓資料看起來比實際新。規格見 `.scratch/data-source-footer/spec.md`。

**Blocked by:** 01 — 頁尾資料來源連結

**Status:** resolved

- [x] 線上建置下載某個伺服器的資料時,在該服快取寫下下載完成的時間;離線建置讀這個時間
- [x] 舊快取沒有時間記錄時,改用該服幹員表檔案的修改時間,不必重新下載
- [x] 建置函式維持純函式:下載時間由建置腳本讀好,連同原始資料作為該伺服器的輸入傳入;索引中每個伺服器的資料版本包含版號與下載時間
- [x] 頁尾項目函式為每個伺服器輸出「YYYY-MM-DD HH:mm(UTC+8)」格式的時間,固定用台灣時區,不受瀏覽器或執行環境時區影響;頭像項目沒有時間
- [x] 「建置 → 查詢」測試:輸入 2026-10-19T04:14:00Z 得到「2026-10-19 12:14(UTC+8)」,國服與台服各自的時間正確
- [x] Playwright 煙霧測試:頁尾含兩個「版號 · 日期 時分(UTC+8)」
- [x] 實際執行一次線上建置與一次離線建置,確認離線建置的時間沿用線上建置當時的下載時間
