# 01 — 頁尾資料來源連結

**What to build:** 頁尾的「國服」「台服」「頭像」三個字變成超連結,在新分頁開啟各自資料來源的 GitHub 資料庫;懸停時顯示「資料來源:<名稱>」(例如「資料來源:Kengxxiao/ArknightsGameData」),手機上點了直接跳過去。原本那行純文字的資料來源說明拿掉。國服、台服、頭像三個資料來源只定義一次,建置腳本的下載位置與頁尾連結都從同一份清單來。規格見 `.scratch/data-source-footer/spec.md`。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 國服、台服、頭像三個資料來源的名稱與資料庫網址集中定義一次;建置腳本下載遊戲資料與頭像的位置由它衍生
- [x] 查詢端新增一個純函式:輸入索引,輸出頁尾項目清單——每個伺服器一項(顯示名、版號、資料來源名稱與網址),頭像一項(只有名稱與網址);索引沒有台服資料時不列台服
- [x] 頁尾依項目清單排成一行、以「·」分隔,窄螢幕可換行;「國服」「台服」「頭像」是新分頁超連結,並阻擋開啟頁取得原頁面的控制權
- [x] 懸停提示用瀏覽器原生提示,內容為「資料來源:<名稱>」
- [x] 移除原本的純文字資料來源說明
- [x] 「建置 → 查詢」測試:頁尾項目的版號、資料來源名稱與網址正確,頭像項目沒有版號;沒有台服資料時不列台服
- [x] Playwright 煙霧測試:三個連結指向各自的資料來源網址,並設定在新分頁開啟
