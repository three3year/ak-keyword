# 分流標籤

技能以五個標準分流角色溝通。本檔把這些角色對應到本 repo 議題追蹤實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 repo 的標籤    | 意義                         |
| ------------------------ | ----------------- | ---------------------------- |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這個議題       |
| `needs-info`             | `needs-info`      | 等待回報者補充資訊           |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可交給 AFK agent   |
| `ready-for-human`        | `ready-for-human` | 需要人工實作                 |
| `wontfix`                | `wontfix`         | 不會處理                     |

技能提到某個角色時(例如「套用 AFK-ready 分流標籤」)，使用此表中對應的標籤字串。

要改用其他詞彙時，編輯右側欄位即可。
